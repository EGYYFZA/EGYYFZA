## About

I'm Seggy, a UI/UX Designer and Web Developer. My projects span web interfaces, interactive prototypes, and research in Information Systems.

This portfolio brings together frontend development with React and TypeScript, a gesture-controlled creative application, and Python work involving Indonesian news data and OCR.
